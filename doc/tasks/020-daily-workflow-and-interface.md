## 用户闭环

- 默认进入清晰的日常对话，助手切换与当前状态可见，不让配置表单占据主要工作区。
- 事项、提醒、记忆可直接发现和操作；通知或业务入口打开具体对象时让目标进入视野。
- 连接、助手、资料权限、存储等设置按目的组织；高级参数渐进展开，不能把必要配置藏成不可用。
- 用中文用户意图解释章节整理、资料整理和自动后台工作，区分状态、操作与配置；保持预算、接收权限和失败恢复可理解。
- 统一布局、字级、间距、颜色、按钮、空状态、错误状态和窄窗口表现；保持完整功能、键盘操作及安全边界。
- 不以删除功能、占位界面或只换配色替代流程整理。新手能创建助手、连接模型、开始对话并找到数据位置；日常用户能处理事项/提醒、查看记忆与自动工作状态。
