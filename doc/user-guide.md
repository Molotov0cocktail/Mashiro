# Mashiro 使用指南（当前候选）

当前仍在整体功能与Windows制品验收，尚无本程序最终发布版本。本指南描述已实现的使用入口；安装下载地址、精确版本、最终验证和限制会在发布验收后填写到发布说明，不以开发构建代替正式安装包。

## 开始对话

先创建助手，再在连接设置中配置服务地址、模型和凭据，并将模型绑定给助手。连接可以复用，助手的身份、人设和基础形象独立保存。临时凭据只在本次运行有效；持久凭据由Windows当前用户保护。

正常对话保存时间线，可浏览、检索并选择局部上下文。在旧轮次展开“查看本轮业务与工具回执”，可以核查原业务结果、处理待确认操作或进入关联事项；查看回执不会重新发送对话。严格临时对话不自动保存，明确保存后才成为正常历史。切换助手、取消回答或恢复应用不会自动重发上一条消息；结果未知的业务操作应先核查原回执，再决定重试。

## 模型能力

连接与模型的能力面板分别说明普通回答、流式、工具、思考协议和其他能力的验证状态。当前GLM-5.3-FLASH已有指定端点的真实角色证据；DeepSeek官方端点的deepseek-v4-flash/pro提供有限保留思考适配，本地测试通过不代表已完成真实端点验证。其他托管地址不能直接继承官方端点的权限或能力。

保留式思考不会显示为普通聊天正文。开启工具时，选中的旧轮需要完整、同接收方和同模型的协议；缺失、不兼容或超出预算时会拒绝发送，可改选不含该旧轮的上下文。更换模型不会自动扩大资料授权。

## 资料和权限

助手可读取的资料范围与具体模型接收资料的权限分别设置。允许助手读取，不表示已允许外发；更换连接或模型后请核对实际接收方。后台功能也遵守这些边界。

可以在对话中明确记住、纠正或删除资料，也可以在记忆区查看和操作。每轮默认收起的“记忆来源与变更”面板可查看本轮实际提供的记忆版本与变更，并进入记忆对象。提供给模型不等于能证明模型在回答中使用了它；来源已撤回、版本失效或权限变化时，旧正文不再展示。观察中的推测不等同于用户陈述；可接受、纠正、拒绝或标记争议。已接受记忆的后续治理进入记忆区，删除和撤回按界面展示的影响确认。

垃圾区内容退出召回但可恢复；压缩与原文回收是不同操作。持久区不会自动降级。容量与期限规则已确认，正在实施：默认持久区已接受记忆正文上限100 MiB，暂存90天后进入可恢复垃圾区，两项均可调整或关闭；垃圾永不自动永久清空。当前内部安装候选尚未包含该设置和自动期限逻辑。

## 事项和提醒

正式事项包括目标、项目、任务、承诺和等待事项。对话中的明确指令按权限执行；模型推测出的事项先进入提案，可确认、否决、暂缓或继续协商。接受前不算正式事项，也不会自动成为提醒；当前功能不代表已接入真实Clender日历。

提醒需保存确定时间与时区。默认在休眠或重启后补发过去24小时内的未处理提醒：同一事项仅最新一条，多事项合并通知；更早的进入过期待处理列表，已完成或取消事项不补发。窗口可调整，也可关闭补发。

关闭窗口后程序驻留托盘，提醒继续运行；选择明确退出后不再保证提醒。登录启动为可选设置。Windows可能禁用通知或不展示弹窗，运行记录会区分派发、观察到显示、失败和结果未知，不能把API调用当作用户已经看见。

## 日常与运行

在“日常与运行”分别配置观察、简报、复盘、每周规划和截止变更。启用前选择实际模型、资料范围、调用预算、时间及恢复策略；不要把普通聊天已可用当作所有后台角色已获授权。

运行页面可以查看业务记录、当前问题和分类用量，并按助手、角色、功能、连接、模型及时间筛选。用量未知会单列，不能当作零。报告展示来源和覆盖范围；部分资料被限制或截取时，不能视为完整资料库总结。

## 数据位置、备份和恢复

程序安装位置与数据位置独立。首次启动明确选择默认位置、已有数据集或新的空目录；自定义目录可使用中文和空格，也可选择可写的安装目录下 `data`。数据位置失效时进入恢复选择，不会静默建立第二份空数据。

正式程序的“数据与备份”菜单可查看当前位置、完整备份、复制到新位置、选择已有数据集，或从完整备份还原。备份前程序会停止当前工作并关闭存储；备份完成后退出，数据迁移或切换成功后重启。复制迁移保留原位置数据。

完整备份包含历史、记忆正文、事项及其权限、删除抑制、来源和业务回执；单独导出Markdown不能代替。备份中的受保护凭据需要原Windows用户，换用户后须重新提供凭据。

还原始终选择新的空目录，并明确确认备份时间与回退影响，现有数据保留原位。旧快照不包含备份之后的新正文；恢复会应用本机仍可核验的后续删除、纠正和撤权记录，缺失的纠正正文会显示不可用，不以旧内容冒充最新内容。无法核验必要的治理记录时停止恢复。恢复后的连接与自动后台工作保持停用，需重新检查配置并明确启用。若当前数据库无法打开，启动恢复入口仍可选择完整备份，核验和启动准备通过后才更改指向。

在新机器或全新配置中恢复时，只能应用备份携带的已知治理记录。如果原数据和原配置记录均已丢失，无法从旧备份推断备份之后未保存的删除、纠正或撤权。请妥善保留最新完整备份；原配置中已知但无法核验的记录不会被当作不存在。

恢复会保留备份中的受保护凭据文件。若本机已知该凭据后来被撤销，或备份后连接版本已改变而无法确认备份中的凭据仍是当前凭据，恢复后不会读取或使用它；这不代表旧文件已物理删除。未变更且未撤销的凭据仍可由原 Windows 用户解密。请明确提供新的持久 Key 以重新启用。临时 Key 仅在当前运行期间有效，退出后仍保持旧凭据的撤销状态。

## 安装、更新与卸载

最终安装、更新、卸载及恢复说明以通过验收的版本发布说明为准。当前支持路线是下载安装包进行更新，不声称已经实现无人值守自动更新。

安装程序采用普通用户范围。卸载按已知程序文件清单清理，不递归删除安装根；业务数据和未知文件保留。升级前保留可校验完整备份；旧程序不能直接打开不兼容的新schema，应使用已验证的旧程序与兼容备份恢复步骤。

签名状态会如实写入发布说明。未签名版本不应被描述成已签名，也不需要关闭Windows系统防护来测试安装。
