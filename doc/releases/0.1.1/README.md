# Mashiro 0.1.1 修订版

状态：发布候选准备中，尚未发布。最终安装包、校验值和下载地址须在制品验收通过后补入。

## 本次改善

- 明确显示尚未确认的已有数据位置，可选择继续使用、数据管理或退出；已确认的位置在正常重装后继续使用，不会每次重复提示。可以显式新建并切换到独立空数据集，原数据会保留。
- 新建空数据使用独立的数据集身份，不继承旧助手、历史、记忆、事项、连接或凭据。数据切换成功后重启生效。
- 启动失败提供分类原因、发生阶段和诊断编号；无法确认启动资源已关闭时，退出后再恢复，避免在不确定状态中切换数据。
- 以对话、事项、提醒和记忆组织日常入口；助手、连接和数据集中到设置，自动工作与运行记录分别展示。
- 对话与设置之间保留草稿和正在生成的回答。后台与权限配置按用途展开，未保存状态仍可见。
- 统一布局、间距和颜色，适配系统深浅色及较窄窗口；从事项和权限入口跳转时展开相应内容。

## 安装与数据

程序安装位置和业务数据位置相互独立。更换安装目录或重新安装不会自动清空已有数据。首次使用时选择数据位置；已有数据的用户可从“数据与备份 → 查看当前数据位置”确认位置。

如需全新开始，使用“数据与备份 → 新建空数据集并重启…”，并选择另一个空目录。原数据不会被删除，之后仍可显式选择已有数据集。完整备份包含治理状态和受保护凭据；跨 Windows 用户恢复后，需要重新提供凭据。

升级前建议使用应用内完整备份。升级、卸载/重装和失败恢复的实际验证结果，以及最终制品的签名状态，将随发布验收补齐；本候选说明不代表这些验证已通过。
