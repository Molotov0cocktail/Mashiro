Mashiro 是 Windows 11 x64 上的单用户、本机优先桌面助理。你可以配置多个助手，保存连续对话，管理记忆、事项和提醒，并按需开启日常整理。

## 开始使用

1. 从 [Mashiro v0.1.0 发行页](https://github.com/Molotov0cocktail/Mashiro/releases/tag/v0.1.0)下载 `Mashiro-0.1.0-win-x64-setup.exe`，按 [`SHA256SUMS.txt`](https://github.com/Molotov0cocktail/Mashiro/releases/download/v0.1.0/SHA256SUMS.txt)核对文件。安装器使用当前 Windows用户权限，可选择程序目录。
2. 首次启动选择默认数据位置，或指定自己的本地目录。程序与数据位置独立；可使用中文、空格路径，也可使用可写安装目录下的 `data`。
3. 创建助手，设置人设和基础形象。在连接设置填写服务地址、模型及自己的 API Key，再将模型绑定给助手。
4. 分别核对助手读取范围与实际服务接收资料的权限，然后开始对话。程序不预置 API Key；模型调用可能由你使用的服务计费。

正常对话会保存时间线；严格临时对话不读取正常历史和记忆，也不自动保存对话；只有明确保存才写入时间线。临时凭据退出后失效；持久凭据使用Windows当前用户保护。

## 可以做什么

- 浏览、检索对话，选取局部上下文，查看旧轮业务回执及本轮记忆来源与变更。
- 通过对话记住、纠正和删除信息；查看来源与性质，管理持久、暂存和垃圾区。默认持久正文容量 100 MiB、暂存 90 天，两项均可调整或关闭，垃圾不会自动永久清空。
- 创建和跟进目标、项目、任务、承诺和等待事项。模型推测先成为提案，可确认、否决、暂缓或协商；确认前不会成为正式事项或提醒。
- 保存确定时间与时区的提醒。关闭窗口后可驻留托盘；明确退出会停止后续提醒调度，已投递给 Windows的通知仍可保留，点击后可启动程序定位事项。默认补发过去 24 小时内的未处理提醒，同一事项只补最新一条，较早提醒进入过期待处理列表。
- 按授权、资料范围、时段和预算启用章节整理、仓储员、观察、简报、复盘、每周规划与截止变更；在运行页面查看状态、业务记录和分类用量。

## 更新、备份与恢复

更新采用下载安装包的方式。在“数据与备份”中创建完整备份并正常退出，再运行新安装包。完整备份包括数据库、接受的Markdown正文和相关治理状态；只导出Markdown不足以恢复全部数据。

卸载清理程序及其系统集成，业务数据和未知文件保留。直接升级或同版重装应保留登录启动选择；完整卸载会清除该登记，随后重新安装不会自动恢复此前的开启状态，需要时须在提醒设置中重新明确启用。重装后，已有数据定位仍有效时会直接打开原数据，可在“数据与备份”中查看当前位置；只有出现设置或恢复窗口时，才重新定位或选择已有数据集。旧程序不能直接读取不兼容的新数据结构；需要回退时，使用兼容旧程序的完整备份还原到新的空目录，保留现有数据原位。

原数据位置丢失、手上只有完整备份，而当前恢复位置窗口没有备份按钮时，可先记录原位置，明确选择一个全新空目录 A 建立中转数据集并进入应用，再从“数据与备份”菜单把原备份还原到另一个全新空目录 B。选择 A 会主动改变当前定位，A 不是恢复结果；B 不能覆盖 A、原数据位置或备份。完整步骤见 [`Mashiro-0.1.0-install-upgrade-guide.md`](https://github.com/Molotov0cocktail/Mashiro/releases/download/v0.1.0/Mashiro-0.1.0-install-upgrade-guide.md)。

恢复会应用本机仍可核验的后续删除、纠正和撤权记录，缺失的新正文不会以旧正文冒充。无法核验必要治理记录时停止恢复。恢复后，已保存连接会停用，助手原有的连接和模型绑定会清除；请在“连接与文本交流”中重新启用并保存连接，为助手重新绑定连接和模型，再核对历史、记忆和事项的读取与实际接收方许可。实际接收方尚未重新确认或未授权前，部分历史来源正文和工具或业务操作详情会保持不可见。自动后台工作也需重新检查并明确启用。完整备份的受保护凭据通常需要原 Windows 用户；跨用户使用时须重新配置。

## 范围与说明

当前已验证的核心模型流程使用指定智谱端点的GLM-5.3-FLASH；其他模型和能力以界面实际验证状态为准。未验证能力不能据此视为可用。

本版不自动访问邮箱、日记或其他私人数据源，不声称已接入真实AIbrowse或Clender。多助手自动协商、其他原生Provider协议及原文列明的可选/远期内容仍按项目覆盖表保留边界。

本版的第三方声明附件七个文件已与安装包逐项对应。已验证覆盖安装的数据保留、旧登录项清理、新登录设置保留和首次启动状态，整体功能与制品验收已通过。通知点击定位到事项后，事项详情位于较长页面下方，需要向下滚动查看。安装不要求关闭 Windows 系统防护；第三方依赖声明随发布附件和程序提供。
