The trusted coordinator supplies an already-existing configuration directory and an explicitly selected initialized dataset. Strict versioned locator/manifest identities distinguish first configuration from unreadable or corrupt existing state. Missing data, a PREPARING manifest, missing/non-SQLite database or mismatched identity enters recovery without creating directories/databases. Recovery relocation retains the original dataset UUID. Explicit binding checks the observed locator fingerprint, writes and fsyncs an exclusive same-directory temporary file, then atomically replaces the locator. A cooperative directory lock prevents competing bind operations; it is never silently removed as stale. Paths are local absolute directories with each ancestor checked for symlinks/junctions, and a unique write probe verifies current-user write access. No renderer or existing startup file imports this module yet.
