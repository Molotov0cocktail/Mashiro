## 用户说明一致性检查

两份现有草稿已经一致表达以下内容，定稿时应保持：

- Mashiro 面向 Windows 11 x64，按当前 Windows 用户安装；程序目录与数据位置独立，中文和空格路径受支持；
- 首次启动可选默认位置、已有数据集或新空位置；位置失效时不会偷偷创建空数据冒充旧数据；
- 有效数据定位在卸载重装后可直接打开原数据，只有实际出现设置或恢复窗口时才重新定位或选择已有数据集；
- 原位置丢失且只有完整备份时，空目录 A 只是进入应用的中转数据集，定位会先切到 A；随后从应用菜单把备份恢复到另一个空目录 B，B 才是成功后的恢复位置；
- 完整备份包含数据库、接受的 Markdown 正文、来源、权限、治理、业务和作业状态以及受当前 Windows 用户保护的凭据材料；单独导出 Markdown 不等于完整备份；
- 恢复后连接停用、助手连接和模型绑定清除；用户须重新启用并保存连接、重新绑定连接和模型，再核对历史、记忆、事项的读取与实际接收方许可；未授权前部分来源正文和操作详情不可见；
- 更新方式是下载新版安装器并手动运行，不承诺自动下载或静默更新；更新前先完成完整备份并退出；
- 当前候选签名事实为 `NotSigned`；说明不得要求关闭 Windows Defender、SmartScreen 或单位安全策略；
- 正常时间线与严格临时对话边界、运行期临时 Key 与 Windows 当前用户保护的持久 Key 边界保持不变；
- 默认记忆持久区正文容量 100 MiB，暂存期限 90 天，两项可调整或关闭；垃圾区不会自动永久清空。
