Mashiro 是 Windows 11 x64 上的单用户、本机优先桌面助理。你可以配置多个助手，保存连续对话，管理记忆、事项和提醒，并按需开启日常整理。

## 开始使用

1. 下载 `Mashiro-0.1.0-win-x64-setup.exe`，按 `SHA256SUMS.txt` 核对文件。安装器使用当前Windows用户权限，可选择程序目录。
2. 首次启动选择默认数据位置，或指定自己的本地目录。程序与数据位置独立；可使用中文、空格路径，也可使用可写安装目录下的 `data`。
3. 创建助手，设置人设和基础形象。在连接设置填写服务地址、模型及自己的API Key，再将模型绑定给助手。
4. 分别核对助手读取范围与实际服务接收资料的权限，然后开始对话。程序不预置API Key；模型调用可能由你使用的服务计费。

正常对话会保存时间线；严格临时对话不读取正常历史和记忆，也不自动保存对话；只有明确保存才写入时间线。临时凭据退出后失效；持久凭据使用Windows当前用户保护。

## 可以做什么

- 浏览、检索对话，选取局部上下文，查看旧轮业务回执及本轮记忆来源与变更。
- 通过对话记住、纠正和删除信息；查看来源与性质，管理持久、暂存和垃圾区。默认持久正文容量100 MiB、暂存90天，两项均可调整或关闭，垃圾不会自动永久清空。
- 创建和跟进目标、项目、任务、承诺和等待事项。模型推测先成为提案，可确认、否决、暂缓或协商；确认前不会成为正式事项或提醒。
- 保存确定时间与时区的提醒。关闭窗口后可驻留托盘；明确退出会停止后续提醒调度，已投递Windows的通知仍可保留，点击后可启动程序定位事项。默认补发过去24小时内的未处理提醒，同一事项只补最新一条，较早提醒进入过期待处理列表。
- 按授权、资料范围、时段和预算启用章节整理、仓储员、观察、简报、复盘、每周规划与截止变更；在运行页面查看状态、业务记录和分类用量。

## 更新、备份与恢复

更新采用下载安装包的方式。在“数据与备份”中创建完整备份并正常退出，再运行新安装包。完整备份包括数据库、接受的Markdown正文和相关治理状态；只导出Markdown不足以恢复全部数据。

卸载清理程序及其系统集成，业务数据和未知文件保留。重装后选择原数据集。旧程序不能直接读取不兼容的新数据结构；需要回退时，使用兼容旧程序的完整备份还原到新的空目录，保留现有数据原位。

恢复会应用本机仍可核验的后续删除、纠正和撤权记录，缺失的新正文不会以旧正文冒充。无法核验必要治理记录时停止恢复；恢复后的连接和自动后台工作需重新检查并明确启用。完整备份的受保护凭据通常需要原Windows用户；跨用户使用时须重新配置。

## 范围与说明

当前已验证的核心模型流程使用指定智谱端点的GLM-5.3-FLASH；其他模型和能力以界面实际验证状态为准。未验证能力不能据此视为可用。
