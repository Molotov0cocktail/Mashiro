# Mashiro

Mashiro 是面向 Windows 11、单用户、本机优先的私人助理桌面应用。当前候选已实现助手配置、持续对话与历史检索、记忆与来源治理、事项和提案、确定性提醒、仓储整理及日常后台功能。程序正在进行整体与 Windows 安装生命周期验收，尚未完成正式发布。使用入口见 [使用指南](doc/user-guide.md)，当前工程状态以 [progress](doc/tasks/progress.md) 为唯一入口。

## 使用文本交流与时间线

1. 运行 `npm run dev`，创建或切换本地助手。
2. 在“连接设置”中新建连接，填写名称和 HTTPS Base URL。
3. 输入自己的 API Key，选择仅本次运行使用或由 Windows 保护后持久保存。
4. 为当前助手绑定连接与模型，核对显示的实际接收方。
5. 正常模式记录用户消息、回答和状态，可浏览、检索并选择局部历史上下文。外发资料同时受助手读取范围、实际接收方权限和上下文预算限制。旧轮次可直接展开原业务回执，核查结果未知操作；查看回执不会重新发送消息。
6. 严格临时模式不读取正常历史，也不自动保存正文。可显式“保存到此助手时间线”；保存当前临时会话尚未保存的可见消息与实际状态，运行中先等待或取消。保存成功后仍为临时模式，再次保存不会重复插入已保存内容。清空临时会话不删除正常时间线。

明确退出应用时会记录已收到的部分回答和中断状态；重启读取本地记录，不自动重发请求。失败、取消、中断的回答不作为后续正常外发上下文。临时正文及进程临时 Key 不随重启恢复。产品不预置 API Key；持久 Key 在仓库外由 Electron `safeStorage` 保护，保护不可用时拒绝持久保存。

当前已审源码及适用验证由 [项目覆盖表](doc/tasks/program-docs-to-release.md) 关联到正式任务和独立报告。源码测试通过不等于全部产品要求或安装制品验收通过；当前内部安装包仅用于隔离验收，最终下载地址将在实际发布并核验后提供。

## 开发命令

- `npm ci`，随后 `npm exec install-electron`：按锁文件恢复依赖与 Electron。
- `npm run dev`：启动开发环境。
- `npm run test:focused` / `npm test`：聚焦与全量测试。
- `npm run typecheck`、`npm run lint`、`npm run format:check`：静态验证。
- `npm run build`：构建 main、preload 和 renderer。
- `npm run test:electron`：用两个真实 Electron PID 验证恢复、凭据保护和临时边界。
- `npm run verify`：完整验证链。

运行数据位于仓库外；开发数据在 appData 下的 `Mashiro Development`，E2E 使用带所有权标记的唯一系统临时目录。安装版分别选择程序位置和数据位置，支持可写安装目录下的 `data`。完整备份、迁移与恢复说明见使用指南；跨版本升级、治理保留和卸载数据保护仍按实际制品逐项验收。

## 当前边界

容量与期限默认已确认：持久正文100 MiB、暂存90天，两项可调整或关闭，垃圾永不自动永久清空；对应源码已通过独立功能、性能修复与整合验证，最终安装态验收继续。实际系统通知、最终安装更新恢复及发布下载仍在验收。AIbrowse、Clender、邮箱和日记等真实私人数据源没有因持续开发而自动接入。可选及远期要求的原始范围、已实现功能和剩余问题均保留在项目覆盖表中。
